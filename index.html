About

Full-stack Android. Web on the side.

I don't just write code for Android — I build the entire stack. From compiling AOSP ROMs from source, to patching kernels at the C level, to crafting custom recoveries that boot on hardware nobody else supports. I've shipped Lunaris, Evolution X, crDroid, AxionOS, Project Infinity X, Project ASCP, Rising OS, Avium UI and more across multiple devices.

My main project is Origin Kernel — a feature-packed kernel for Mediatek chipset-based Nothing devices (Phone (3a) Lite & CMF Phone 2 Pro). Custom schedulers, root via KernelSU-Next, network tuning, power management — the whole deal.

On the web side, I build with HTML, CSS, JavaScript, and TypeScript. Clean UIs, no bloat. Currently picking up C++ to go even deeper.

What I actually do

From source code to a running device — here's the full picture.

⚡

Compile ROMs

Sync AOSP trees, patch device trees, fix build errors at 3 AM, and produce flashable zips that actually boot. Shipped Lunaris, Evolution X, crDroid, AxionOS, Project Infinity X, Project ASCP, Rising OS, Avium UI and more.

⚙

Build Kernels

Write and patch C code at the kernel level. Custom schedulers, memory management, network stack tuning. Maintaining Origin Kernel for Mediatek-based Nothing devices.

⚡

Flash Recoveries

Port TWRP, build custom recoveries, and make sure users can actually back up, restore, and flash on hardware that wasn't designed for it.
