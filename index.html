01 — About

Full-stack Android.
Web on the side.

From source sync to a bootable zip — I own the whole pipeline.

I don't just write apps for Android — I build the entire stack. Sync AOSP trees, patch device trees, fix maple-brained build errors at 3 AM, and produce flashable zips that actually boot. I've shipped Lunaris, Evolution X, crDroid, AxionOS, Project Infinity X, Rising OS, Avium UI and more.

My flagship is Origin Kernel — a feature-packed kernel for Mediatek-based Nothing devices (Phone (3a) Lite & CMF Phone 2 Pro). Custom schedulers, KernelSU-Next root, BBRv3, ZRAM tuning, power management — the whole deal.

On the web I build with HTML, CSS, JS and TypeScript. Clean UIs, zero bloat. Currently going deeper with C++.
